# Tend v0.2 memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each session gets the following, all local and with zero AI tokens:
- a briefing (goal, instructions, what was done, files edited)
- live git facts
- its own worktree, or in-place mode
- overlap detection
- pause / resume / archive
- Claude's trust dialog surfaced as "needs you"

**Architecture:**
- **New modules:**
  - `git.ts` holds every git command, argv-only, with `--no-optional-locks` on reads.
  - `briefing.ts` is a pure fold over stored events.
  - `workspace.ts` orchestrates worktree create, pause, resume and archive.
  - `overlap.ts` is a pure intersection.
- **The registry:**
  - It gains `pause`, `resume`, `archive`, `briefing` and `refreshGit`.
  - Git facts refresh asynchronously, debounced 300 ms after hook events and every 10 s.
  - Overlap is a flag on the session view, never a state.
- **Claude's session id is chosen by Tend** (`--session-id <uuid>`) and reused with `--resume <uuid>`. Real haiku confirmed that `--resume` restores the conversation.
- **Every launch gets a fresh nonce header**, so hooks from a killed earlier run are dropped.

**Tech Stack:** Node 26 with native TS type stripping, `node:test`, `node:sqlite`, tmux control mode, the git CLI, plain-JS UI with xterm.js. No new dependencies.

## Verified facts (real Claude Code 2.1.312 / git, 2026-10-28)

**Claude:**
- `claude --session-id U` followed by `claude --resume U` restores the conversation.
- `--session-id U` when U's transcript already exists fails with `Error: Session ID U is already in use.` (exit 1).
- `--resume U` with no transcript fails with `No conversation found with session ID: U` (exit 1).
- Transcripts live at `<CLAUDE_CONFIG_DIR or ~/.claude>/projects/<escaped cwd>/<U>.jsonl`.

**git:**
- `git worktree remove` without `--force` exits 0 and **silently deletes gitignored files** (tested with `.env`).

**macOS paths:**
- `os.tmpdir()` gives `/var/folders/…`, but `process.cwd()`, tmux `pane_current_path` and `git rev-parse --show-toplevel` give `/private/var/…`.
- Always compare paths after `realpathSync`.

## Global Constraints

**Code**
- Erasable-only TypeScript: `import type`, `.ts` import extensions, no enums, no namespaces, no parameter properties.
- No native dependencies, and no new npm dependencies (the `scripts/check.mjs` allowlist stays unchanged).
- No file over 600 lines.
- No `console.log` in `src/`; use `logInternal` (in `src/server.ts`) for unexpected errors.

**Subprocesses and git**
- Every subprocess is argv-only (`execFile`/`execFileSync`/`spawn`), never a shell.
- **Every git command:**
  - Run it as `git -C <dir> ...`.
  - Put `--` before positional paths and refs wherever git accepts it.
  - Background reads (status, diff, rev-list, rev-parse, ls-files) start with `--no-optional-locks`, as the first argument after `git`.
- **WIP commit:**
  - First run `git -C <wt> add -A -- .`.
  - Then run exactly: `git -C <wt> -c commit.gpgsign=false -c user.name=Tend -c user.email=tend@localhost commit --no-verify -q -m "tend: paused (WIP)"`.
- `git worktree remove` is never passed `--force`. If it fails, the operation is aborted and the worktree kept.
- Tend never runs `git push`, never deletes a branch except one it created in the same failed `create()` call, and never runs `claude --continue`.
- **Paths:**
  - `home` is `realpathSync`'d once, in `createRegistry`.
  - The worktree path is exactly `<home>/worktrees/<id>`; the paused-files stash is exactly `<home>/paused/<id>/`.
  - Both parent dirs are created with mode 0700.
  - The branch is exactly `tend/<slug>-<id>`. `slug` is the session name lowercased:
    - every run of characters outside `[a-z0-9]` becomes `-`;
    - leading and trailing `-` are trimmed;
    - it is cut to 40 characters and trailing `-` trimmed again;
    - an empty slug becomes `session`.
    - The result must pass `git check-ref-format --branch`.

**Security**
- Every new HTTP route is token-protected (the default `auth: 'token'`).
- Session-scoped routes go through the existing `SESSION_ROUTE` + `isSessionId` + `reg.get` gate.
- **Archived sessions:** `reg.get` returns `undefined` for them, so their routes 404.
- Event data reaches the DOM only via `textContent` / `esc()`, never as raw HTML.
- Tend never accepts Claude's trust dialog itself and never writes `~/.claude.json`.

**Tests**
- Tests use temp repos (`mkdtempSync(join(tmpdir(), ...))`), a temp `TEND_HOME`, and a unique tmux socket.
- Test repos set `user.name`/`user.email` locally.
- Tests that launch fake claude set `CLAUDE_CONFIG_DIR` to a temp dir.
- Tests never touch `~/.tend`, `~/.claude` or a real repo.

**Copy (exact)**
- `Uncommitted changes in <folder name> aren't included in the worktree.`
- `This repo has no commits yet, so the session runs in the folder itself.`
- `Pause needs a session with its own worktree.`
- `Session is still running.`
- `Could not remove the worktree: <first line of git's stderr>`
- `Could not set aside ignored files: <error message>`
- `Branch <branch> no longer exists.`
- Overlap notification (one per newly overlapping pair): title `<name> overlaps <other name>`, body `Both changed: <up to 3 files, comma-separated><, +N more>`.
- Trust notification: title `<name> needs you`, body `Asks you to trust the folder`.

## Review Focus

1. **Pausing a worktree with ignored files (`.env`, `node_modules/`) and untracked build output.** Nothing is lost; resume restores every file byte-for-byte. Tested in Tasks 2 and 5.
2. **Two sessions created from one repo with the same name.** They get distinct branches, and both worktrees exist. Tested in Task 4.
3. **Resuming after the user deleted the `tend/` branch by hand.** It fails with a 400 naming the branch, with no half-built worktree left. Tested in Task 5.
4. **A repo whose path contains a space and `#`.** Create, facts and pause all work. The temp repos live under a `my #repo` folder in Tasks 2, 4 and 5.
5. **The server restarting while one session is paused and one is archived.** Paused stays paused with no facts; archived stays hidden; briefings are identical; a resumed session isn't ended. Tested in Task 6.

### Task 5: Pause, resume, archive, briefing routes

**Files:**
- Modify: `src/workspace.ts`, `src/sessions.ts`, `src/server.ts`
- Test: `test/e2e/lifecycle.test.ts` (new)

**Interfaces:**
- Consumes: Tasks 1–4.
- Produces:
  ```ts
  // workspace.ts
  export function pauseWorkspace(ws: WorktreeWs, stash: string): WorktreeWs;
  export function resumeWorkspace(ws: WorktreeWs, stash: string): WorktreeWs;
  export function archiveWorkspace(ws: Workspace, paused: boolean, stash: string): void;
  // (WorktreeWs = Extract<Workspace, { mode: 'worktree' }>; stash = <home>/paused/<id>)
  // sessions.ts
  Registry.pause(id: string): Promise<SessionView>;
  Registry.resume(id: string): Promise<SessionView>;
  Registry.archive(id: string): Promise<void>;
  Registry.briefing(id: string): Briefing & { state: SessionState };
  ```
- **`pauseWorkspace`:**
  1. `sha = wipCommit(wt)`.
  2. Move each `ignoredEntries(wt)` entry with `renameSync` to `<stash>/<entry>` (mkdir -p parents). On any error, move the already-moved entries back, run `restoreWip` if `sha` is set, and throw `UserError('Could not set aside ignored files: …')`.
  3. `removeWorktree`. On error, move the entries back, run `restoreWip` if `sha` is set, and throw `UserError('Could not remove the worktree: …')`.
  4. Return `{ ...ws, wip: sha }`.
- **`resumeWorkspace`:**
  1. If `worktreeOn(repo, worktree, branch)` is already true, skip to step 4 (idempotent).
  2. If `!branchExists` → `UserError('Branch <branch> no longer exists.')`, with nothing created.
  3. `reAddWorktree`.
  4. If `wip` is set, `restoreWip`.
  5. Move the entries under `<stash>` back (rename), then remove `<stash>`.
  6. Return `{ ...ws, wip: null }`.
- **`archiveWorkspace`:** a worktree that isn't paused gets the same steps as pause. An already-paused one has nothing to remove; its stash is left in place, and the paused WIP commit stays on the branch.
- **Kill-and-wait** (used by pause and archive):
  - Run `tmux.kill(tmuxName(id))`, then poll `tmux.has` every 100 ms until false, for up to 3 s.
  - Then `apply()` a `pane_exit` event (`apply` calls `markEnded`). Skip it if already ended.
- **pause(id):**
  - In place → `UserError('Pause needs a session with its own worktree.')`.
  - Already paused → return the view.
  - Allowed whether running or ended.
  - Steps: kill-and-wait, then `pauseWorkspace`. On success, `updateSession(id, { workspace, paused: true })`, emit, return.
  - On failure the session stays ended (not paused) and the UserError propagates as 400.
- **resume(id):**
  - Allowed only if `paused` or `paneGone(id)`; else `UserError('Session is still running.')`. Running means a live pane, even after a mid-session `SessionEnd`.
  - **Steps:**
    1. If paused: `resumeWorkspace`, then immediately `updateSession(id, { workspace, paused: false })`.
    2. `tmux.kill` to clear a dead pane.
    3. Pick the Claude id: `claudeId`, or for a v0.1 row (`''`) the latest event's `claudeSessionId`. If none, use `randomUUID()`.
    4. `resume = hasTranscript(claudeId)`.
    5. Generate a new `launch` and rewrite the settings.
    6. `updateSession(id, { claudeId, launch, endedAt: null })`, then `apply()` a `resumed` event. The order matters: `endedAt` is cleared first.
    7. `tmux.newSession` in `launchCwdOf`. If it throws, `apply()` a `pane_exit` and rethrow.
- **archive(id):**
  1. Kill-and-wait.
  2. `archiveWorkspace`. On abort: 400, and nothing is archived.
  3. `updateSession(id, { archived: true })`.
  4. Delete the view from `views`.
  5. Emit `{ ...view, archived: true }` once.
- `list()` and `get()` never return archived rows, and the constructor skips them.
- **Routes** (in `sessionRoutes`):
  - `POST pause`, `POST resume` → 200 with the view.
  - `POST archive` → 204.
  - `GET briefing` → 200 with `buildBriefing(store.eventsFor(id), launchCwdOf(cwd, workspace))` plus `state`.
